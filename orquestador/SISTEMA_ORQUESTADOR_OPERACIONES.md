## 🛒 5. MÓDULO 2: ALGORITMO INTELIGENTE DE COMPRAS DE VIERNES (SUMINISTROS)

Para asegurar la frescura marina absoluta del fin de semana, el inventario de mariscos no se almacena por semanas. **Las compras críticas se ejecutan cada Viernes a las 06:30 AM en La Puntilla y mercados locales**.
- **Capacidad Estándar:** **75 bolsas por tanda** (ajustable hacia arriba o abajo según producto y demanda).
- **Política de Sabor:** El producto viene **picante por naturaleza** (receta única con chile serrano fresco).

### 5.1 Ficha Técnica de Consumo por Unidad (1 Bolsa de Tostiaguachile Verde = $170 MXN):
- **Camarón Fresco (Golfo / La Puntilla):** **100 g neto limpio en corte mariposa** (requiere **115 g en bruto** considerando merma de limpieza/desvenado).
- **Limón Colima (Agrio y Jugoso):** 60 ml de jugo puro (~4 a 5 limones medianos, peso bruto equivalente: **180 g a 240 g de limón fresco**).
- **Tostitos Salsa Verde:** 1 bolsa individual oficial (presentación de aprox. 65 g). Las cajas máster contienen **24 unidades**.
- **Pepino Criollo:** 1/2 pieza (120 g calibrado en medias lunas).
- **Cebolla Morada:** 1/4 pieza (40 g desflemada en plumas).
- **Chile Serrano & Cilantro:** 2 chiles serranos (30 g) + 15 g de cilantro por orden.
- **Hielo en escama:** Hielo suficiente para mantener cubetas y hielera a 0°C - 3°C.

### 5.2 Formulación Matemática del Algoritmo de Viernes

Sea $N$ el total de pedidos confirmados en preventa durante lunes a jueves vía WhatsApp (estándar: 75 bolsas):
Se aplica un **Margen de Seguridad Dinámico ($S = 15\%$)** para pedidos espontáneos del sábado y domingo:

$$P_{\text{táctico}} = \lceil N \times 1.15 \rceil$$

A partir de $P_{\text{táctico}}$, el algoritmo calcula de forma exacta:

```
+-----------------------------------------------------------------------------------------+
|                                ALGORITMO DE COMPRAS DE VIERNES                          |
|                                                                                         |
| 1. Camarón Fresco Crudo (kg) :  Kg_Camarón = round( P_táctico * 0.115, 2 )              |
| 2. Limón Colima Fresco (kg)  :  Kg_Limón   = round( P_táctico * 0.242, 2 )              |
| 3. Cajas TOSTITOS SALSA VERDE   :  Cajas_Tost = ceil( P_táctico / 24 )                     |
| 4. Bolsas Tostitos Sueltas   :  Bolsas_Tost = P_táctico                                 |
| 5. Pepino Fresco (kg)        :  Kg_Pepino  = ceil( P_táctico * 0.130 )                  |
| 6. Cebolla Morada (kg)       :  Kg_Cebolla = ceil( P_táctico * 0.045 )                  |
| 7. Chile Serrano (kg)        :  Kg_Serrano = ceil( P_táctico * 0.035 )                  |
| 8. Cilantro Criollo (Manojos):  Manojos_Cil = ceil( P_táctico / 8 )                     |
| 9. Hielo Grado Alim. (Bolsas):  Bolsas_Hielo = 4 + ceil( P_táctico / 15 )                |
+-----------------------------------------------------------------------------------------+
```
